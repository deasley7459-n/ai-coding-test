### Element Plus
- 角色：基于 Vue 3 的桌面端 UI 组件库，提供表格、表单、弹窗、分页、消息提示等组件。
- 稳定用法：项目使用其 `el-table`、`el-form`、`el-dialog`、`el-pagination`、`ElMessage`、`ElMessageBox` 等组件完成用户管理页面的 CRUD 交互。
