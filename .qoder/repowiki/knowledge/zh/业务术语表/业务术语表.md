### 前后端分离
- 定义：本项目采用的架构模式：后端（Spring Boot）仅提供 REST API，前端（Vue 3）独立构建并通过 HTTP 调用接口；开发期由 Vite 代理转发 `/api` 请求到后端，生产期可分别部署。
- 别名：前后端分离架构、REST 前后端分离

### 内存仓储
- 定义：后端数据持久层的临时实现：使用 `ConcurrentHashMap<Long, User>` 存储用户数据，配合 `AtomicLong` 生成自增 ID；服务重启后数据全部重置，生产环境需替换为数据库实现。
- 别名：内存存储、ConcurrentHashMap 存储

### 统一响应结构
- 定义：后端所有 API 返回的固定 JSON 格式 `{ code, message, data }`，其中 `code=0` 表示成功、非 0 表示失败；前端类型定义与之对应，用于统一解析响应体。
- 别名：ApiResponse、统一响应、code/message/data 结构

### API 代理
- 定义：开发环境下，前端 Vite 开发服务器将 `/api/**` 请求转发到后端 `http://localhost:8080`，使前端可在 `localhost:5173` 下直接调用后端接口而无需跨域配置。
- 别名：Vite 代理、/api 代理

### CORS 跨域配置
- 定义：后端通过 `WebCorsConfig` 实现 `WebMvcConfigurer`，允许来自 `http://localhost:5173` 和 `http://127.0.0.1:5173` 的前端对 `/api/**` 发起跨域请求，支持 GET/POST/PUT/DELETE/OPTIONS 方法及携带凭证。
- 别名：跨域配置、WebCorsConfig
