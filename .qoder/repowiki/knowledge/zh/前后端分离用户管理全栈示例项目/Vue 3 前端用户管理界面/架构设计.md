采用典型的 Vue 3 单页应用分层结构：入口 `src/main.ts` 创建 Vue 应用并全局注册 Element Plus（含中文语言包）及图标；`src/App.vue` 仅作为 `<router-view>` 容器；路由由 `src/router/index.ts` 通过 vue-router 的 `createWebHistory` 配置，根路径重定向到 `/users`，未知路径兜底重定向。视图层 `src/views/UserListView.vue` 使用 Composition API (`<script setup>`) 实现用户列表的搜索、前端分页、新增/编辑/删除弹窗交互。数据访问层拆分为 `src/api/request.ts`（基于 axios 封装统一 baseURL、超时与响应拦截器，错误统一通过 ElMessage 提示）和 `src/api/user.ts`（按 RESTful 风格暴露 list/get/create/update/delete 等函数）。类型定义集中在 `src/types/`，被 API 与视图共同引用。构建配置在 `vite.config.ts` 中设置 `@` 别名指向 `src`，开发服务器将 `/api` 代理到 `http://localhost:8080` 的 Spring Boot 后端，形成前后端分离但本地联调时同源请求的模式。
