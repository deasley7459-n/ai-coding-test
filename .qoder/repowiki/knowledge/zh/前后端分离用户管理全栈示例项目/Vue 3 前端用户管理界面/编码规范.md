- API 调用统一通过 `src/api/request.ts` 创建的 axios 实例发起，所有接口以独立函数形式导出并按 RESTful 动词命名（listUsers/getUser/createUser/updateUser/deleteUser）。
- 后端响应统一包装为 `ApiResponse<T>` 泛型类型，axios 响应拦截器自动解包 `response.data`，业务代码直接消费数据字段。
- 错误处理集中在 axios 响应拦截器内，通过 `ElMessage.error` 统一弹出错误信息，业务层 catch 分支保持空实现以避免重复提示。
- 组件内部状态使用 Vue 3 Composition API 的 `ref`/`reactive`/`computed` 声明，表单校验通过 Element Plus 的 `FormRules` 配合 `formRef.validate()` 完成。
- 模块间路径统一使用 `@/` 别名导入（如 `@/api/user`、`@/types/user`），避免相对路径嵌套。
