采用经典的分层架构：`controller` 层通过 `@RestController` 暴露 `/api/users` 下的 REST 端点；`service` 层封装业务逻辑（含启动时初始化示例数据）；`repository` 层以 `ConcurrentHashMap` + `AtomicLong` 实现的内存仓储替代数据库，便于演示；`model` 与 `dto` 分别承载领域实体与请求/响应契约。全局异常由 `GlobalExceptionHandler`（`@RestControllerAdvice`）统一捕获并转换为统一的 `ApiResponse<T>` 结构体。跨域通过 `WebCorsConfig` 开放给本地 Vite 前端（5173 端口）。应用入口为 `BackendApplication`，配置集中在 `application.yml`。测试位于 `src/test/java`，包含集成测试用例。
