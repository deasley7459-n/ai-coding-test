- 所有 HTTP 响应统一封装为 `ApiResponse<T>` 记录类，通过静态工厂方法 `success` / `error` 构造，避免在控制器中重复组装响应体。
- 请求参数使用 Java record 配合 `jakarta.validation` 注解（`@NotBlank`、`@Email`、`@Size`）进行声明式校验，并在控制器中以 `@Valid` 触发。
- 依赖注入通过构造器完成，字段声明为 `final`，遵循不可变设计。
- 领域模型使用 Java record（如 `User`、`UserRequest`、`ApiResponse`）表达不可变数据传输对象。
- 业务异常（如 `UserNotFoundException`）在服务层抛出，由 `GlobalExceptionHandler` 中的 `@ExceptionHandler` 映射到对应 HTTP 状态码并返回统一错误结构。
